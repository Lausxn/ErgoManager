Seguridad de la cuenta

Estás utilizando una contraseña temporal. Para mantener tu cuenta protegida, te recomendamos actualizarla antes de continuar usando MGS Ergo Manager.

Requisitos de la nueva contraseña
  • Al menos 8 caracteres.
  • Una letra mayúscula y una letra minúscula.
  • Un número.
  • Un carácter especial.
El cambio de contraseña se realizará desde la opción autorizada del sistema para la cuenta del usuario.
